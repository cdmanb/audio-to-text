# 音频转文字

批量将 mp3/wav 音频转为中文文字，去语气词 + 校对 + 摘要，输出 `.md`。

## 使用

桌面双击 **音频转文字.app** 启动。

或命令行：

```bash
./start.sh
```

## 模型

全部通过 oMLX 本地推理 (`localhost:8000`)：

| 步骤 | 模型 |
|------|------|
| 语音转文字 | Qwen3-ASR-1.7B-8bit |
| 校对 + 摘要 | Qwen3.6-35B-A3B-8bit |

LLM 可切换为 OpenAI 在线 API。

## 输出

| 文件 | 内容 |
|------|------|
| `xxx_校对稿.md` | 校对后正文 |
| `xxx_重点摘要.md` | 分层重点提取（可选） |
